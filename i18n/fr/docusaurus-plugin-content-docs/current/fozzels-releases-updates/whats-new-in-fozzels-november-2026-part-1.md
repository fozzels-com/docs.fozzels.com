![Nouveautés de Fozzels, novembre 2026, partie 1](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/01-cover.jpg)

C'est notre plus grande mise à jour depuis Multi Flow. Nous avons reconstruit les Content Flows depuis le début : vous configurez un Flow en six étapes guidées, vous construisez le prompt à partir de blocs, et le nouveau Brand Profile garde la voix de votre marque à un seul endroit. Voici les nouveautés :

- **De nouveaux Content Flows.** Six étapes guidées, des prompts construits à partir de blocs, des tests avec des scores et un lancement sûr.
- **Brand Profile.** Enregistrez une seule fois votre rôle, votre public cible, votre ton et vos règles. Chaque nouveau Flow démarre avec eux.
- **Assistant de prompt.** Fozzels écrit en un clic le premier prompt d'un nouvel attribut.
- **Deux nouveaux modèles GPT-6.2**, et des attributs que vous pouvez envoyer au prompt en HTML.
- **Des noms de fichiers propres** dans les téléchargements d'images, **les modèles de produits Akeneo comme parents** et une génération d'images plus fiable.

## Les Content Flows réinventés

La configuration d'un Flow est maintenant un parcours guidé en six étapes. Chaque partie de votre prompt est un bloc que vous activez ou désactivez, et la voix de votre marque se trouve à un seul endroit : le nouveau **Brand Profile**. Vous avez plus de contrôle avec moins de travail, pour votre premier Flow comme pour de nombreux Flows.

![Le Flow guidé : sélectionnez ce que vous voulez générer et voyez à quel point votre catalogue est complet](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/02-guided-flow.png)

Pour une description complète de chaque étape, consultez [4.1.2. Créer un Content Flow : les six étapes](/content-creation-flows/creating-a-new-content-flow-and-initial-settings/).

### Un Flow guidé en six étapes

1. **Store** : sélectionnez votre intégration, votre site web et votre vue de boutique.
2. **What and with what?** : sélectionnez les champs à générer et vos produits. Vous voyez combien de produits ont déjà une valeur dans chaque champ.
3. **Enrich the text** : sélectionnez le modèle d'IA et construisez un prompt commun à partir de blocs : qui écrit, pour qui, sur quel ton et d'où viennent les faits.
4. **Fields** : définissez la longueur, la structure et le format de chaque champ.
5. **Test** : générez des textes pour des produits réels et voyez les scores avant de dépenser de l'argent pour de nombreux produits.
6. **Launch** : définissez combien de produits Fozzels traite chaque jour et si vous approuvez d'abord les textes.

Chaque étape vous indique ce qui manque avant de pouvoir continuer.

### Step by step ou Expert view

**Step by step** vous guide à travers les étapes, une à la fois. Utilisez ce mode pour les nouveaux Flows et les nouveaux membres de l'équipe. **Expert view** affiche le Flow complet sur une seule page, avec les paramètres avancés, comme le seuil de confiance, le délai d'attente entre les Flows et ce que fait Fozzels quand un produit n'a pas encore d'image. Vous pouvez passer d'un mode à l'autre à tout moment en un clic.

### Des prompts construits à partir de blocs

Vous n'avez pas à écrire de longs prompts à la main. Activez les blocs dont vous avez besoin, et Fozzels crée le prompt pour vous :

- **Le style du texte** : le rôle, le public cible et le ton. Sélectionnez chacun en un clic.
- **Principes de neuromarketing** : quatre principes d'écriture issus d'une recherche menée avec l'Université Érasme de Rotterdam. Fozzels vous indique les principes qui conviennent à vos produits.
- **D'où viennent les faits** : les attributs de votre boutique, jusqu'à cinq photos produit et une recherche sur Internet pour les caractéristiques du fabricant. L'IA utilise uniquement les sources que vous activez. Elle n'invente pas de faits.
- **Mots-clés, snippets et règles** : vos propres termes de recherche, des instructions que vous réutilisez, des mots à éviter et les règles de vérification standard de Fozzels.

Les champs supplémentaires, comme SEO Title et SEO Description, utilisent le même prompt principal et n'ont besoin que d'une consigne courte. Un aperçu en direct montre l'instruction avec les données d'un produit réel.

### Assistant de prompt : un prompt prêt en un clic

Quand vous ajoutez un nouvel attribut à un Flow et que cet attribut n'a pas de prompt, Fozzels peut maintenant écrire le premier prompt pour vous. Vous pouviez déjà demander à l'assistant dans le chat, mais ce bouton le fait en un clic.

<video controls muted playsInline preload="metadata" width="100%" title="Assistant de prompt : partir d'un prompt prêt à l'emploi" src="/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/03-prompt-assistant.mp4"></video>

1. Ajoutez un nouvel attribut à votre Flow et ouvrez son prompt vide.
2. Dans le message "The prompt is empty. Let AI write a first one…", cliquez sur **In the store's language** ou sur **In my language**.
3. Fozzels écrit un prompt pour les attributs de votre boutique. Il ajoute les bons attributs, par exemple **Title**, **Vendor** et **Product Type**, et les place dans des blocs conditionnels pour ignorer les attributs vides. Il ajoute aussi des règles pour ce champ.
4. Lisez le prompt, modifiez-le si nécessaire et enregistrez-le.

![Un prompt de l'assistant de prompt, avec des blocs d'attributs et des règles](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/04-prompt-assistant-result.png)

Sélectionnez la langue de la boutique pour obtenir un prompt que le modèle peut utiliser tel quel. Sélectionnez votre propre langue si vous voulez lire et modifier le prompt plus facilement.

### Un contrôle complet pour chaque champ

Chaque champ a ses propres paramètres : une longueur, une structure en sections (titres, paragraphes et listes à puces, chacun avec sa propre instruction et sa propre condition) et un format : HTML ou texte brut. Vous pouvez aussi ajouter un **Trust block** à la fin de chaque description, par exemple votre politique de retour, votre garantie ou votre magasin physique. Fozzels l'ajoute mot pour mot, ou l'IA l'intègre au texte avec ses propres mots.

### Testez avant le lancement

Générez des textes pour des produits réels et comparez côte à côte le texte actuel et le nouveau texte. Fozzels donne aux deux textes un score de 0 à 100 pour le SEO, le GEO (la visibilité dans la recherche IA), la lisibilité par l'IA, les mots-clés, la conversion et le neuromarketing. Il explique chaque score en une courte phrase et affiche l'amélioration totale.

![Scores du texte actuel et du nouveau texte, pour chaque sujet](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/05-test-scores.png)

### Sûr par défaut

Un nouveau Flow démarre prudemment. Une limite quotidienne de produits réduit les coûts et le travail de relecture, et les nouveaux textes attendent votre approbation avant que Fozzels ne les envoie à votre boutique. Quand vous avez confiance dans les résultats, passez à la publication automatique. Fozzels peut aussi écrire un nouveau texte quand le produit change, et vous pouvez connecter des workflows qui s'exécutent après chaque texte.

![Paramètres de lancement : limite quotidienne, approbation et mises à jour automatiques](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/06-launch-settings.png)

### Voici le Brand Profile

Enregistrez une seule fois la voix de votre marque et utilisez-la partout. La nouvelle page **Brand Profile** dans les paramètres de votre compte définit les réglages de départ de chaque nouveau Content Flow : le modèle d'IA, qui écrit, pour qui et sur quel ton, les principes de neuromarketing et les mots-clés que l'IA utilise, et ce qui ne doit jamais figurer dans le texte.

![La page Brand Profile](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/07-brand-profile.png)

- **Un profil pour chaque marque, boutique ou gamme de produits** : par exemple un pour les descriptions et le SEO, un pour la FAQ et un pour des soldes. Les nouveaux Flows démarrent avec votre profil par défaut.
- **Charger ou enregistrer depuis un Flow** : à l'étape **Enrich the text**, chargez un autre profil ou enregistrez les paramètres du Flow comme nouveau profil.
- **Un clic dans chaque Flow** : sélectionnez un rôle, un public cible ou un ton enregistré quand vous construisez un prompt, ou créez-en un nouveau. Cliquez sur **Make default** pour l'utiliser dans tous les nouveaux Flows.
- **Vos propres instructions** : ajoutez d'autres informations que l'IA doit toujours connaître, par exemple la façon de s'adresser au lecteur ou le fait que vous expédiez en 24 heures.

Vous pouvez toujours modifier chaque paramètre dans un Flow. Quand vous modifiez un profil, Fozzels ne modifie pas vos Flows existants. Le résultat : le même style de contenu dans toutes vos boutiques, langues et canaux, sans copier de prompts.

Pour plus d'informations, consultez [Brand Profile](/content-creation-flows/creating-a-new-content-flow-and-initial-settings/#brand-profile).

### Autres nouveautés dans les Content Flows

- **Des taux de remplissage partout** : voyez pour chaque champ et chaque attribut à quel point votre catalogue est complet.
- **Les textes ALT** ont leur propre mode de Flow.

## Modèles d'IA

### Nouveaux modèles de texte : GPT-6.2 Astra et GPT-6.2 Sol

Deux nouveaux modèles de texte d'OpenAI sont maintenant disponibles dans Fozzels.

![GPT-6.2 Astra et GPT-6.2 Sol](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/08-gpt-6-2-models.jpg)

- **GPT-6.2 Astra** est le nouveau modèle de pointe d'OpenAI, pour vos projets les plus difficiles. Utilisez-le pour des descriptions premium, des produits avec de nombreux attributs et des prompts complexes. Il utilise moins de tokens de sortie que GPT-6 Astra : chaque texte coûte donc moins cher.
- **GPT-6.2 Sol** est le modèle efficace pour le travail quotidien. Il a le même prix que GPT-6.1 Sol : c'est donc un bon choix pour les grands catalogues.

Sélectionnez le modèle dans l'AI Configuration de votre Flow, comme avant.

### Les Flows GPT-5 utilisent maintenant GPT-5.4

OpenAI arrête GPT-5 dans son API le 11 décembre 2026. Nous avons fait passer tous les Flows qui utilisaient GPT-5 à GPT-5.4 : votre génération continue. Vous n'avez rien à faire.

## Contenu texte

### Envoyer des attributs au prompt en HTML

Jusqu'à présent, les attributs du prompt envoyaient uniquement du texte brut au modèle : Fozzels retirait les balises HTML et les liens de l'attribut source. Pour les attributs qui contiennent du HTML, vous pouvez maintenant envoyer le HTML d'origine.

1. Dans l'éditeur de prompt, cliquez sur un attribut, par exemple **Description**.
2. Activez **Send as HTML**. Un badge orange **HTML** s'affiche sur l'attribut.
3. Regardez la **Preview** : le modèle reçoit maintenant le balisage complet, avec les titres, les listes et les liens.

![L'option Send as HTML sur un attribut du prompt, et le HTML dans la Preview](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/09-send-as-html.png)

C'est utile quand la structure est importante : quand vous traduisez des descriptions, quand vous réécrivez ou améliorez des textes, et quand vous voulez garder les liens internes pour le SEO.

## Images

### Téléchargements d'images : des noms de fichiers sans l'ID Fozzels

Une nouvelle option à l'étape **Automation** d'un Image Flow retire l'ID Fozzels des noms de fichiers dans le téléchargement ZIP. Les fichiers portent exactement le nom de votre modèle (par exemple `2900268758010_01.jpg`) : vous pouvez donc les importer directement dans des systèmes comme SRS. Vous n'avez pas à les renommer.

<video controls muted playsInline preload="metadata" width="100%" title="Des noms de fichiers propres dans les téléchargements ZIP" src="/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/10-zip-file-names.mp4"></video>

1. Dans votre Image Flow, allez à l'étape 4, **Automation**.
2. Sous **File name for pushed and downloaded images**, définissez votre modèle de nom, par exemple `{id}_{productType}`. Sélectionnez des attributs dans la liste pour les ajouter.
3. Sélectionnez **Leave out the Fozzels ID (_{id}) in ZIP downloads**.
4. Dans l'**Image Completion List**, sélectionnez vos images, puis cliquez sur **Actions → Download images (ZIP)**.
5. Téléchargez le fichier ZIP depuis **Export / Generated Data**. Le fichier est disponible pendant 24 heures.

![Le modèle de nom de fichier et l'option Leave out the Fozzels ID à l'étape Automation](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/11-file-name-template.png)

Si deux fichiers d'un même ZIP reçoivent le même nom, le deuxième fichier reçoit `_01`, le troisième `_02`, et ainsi de suite. Fozzels n'écrase donc aucun fichier. Les images que Fozzels envoie à votre boutique gardent toujours le suffixe `_{id}.{ext}`.

### Acceptez les images quand vous voulez

Avant, une image se synchronisait avec votre boutique uniquement si vous l'acceptiez dans les 14 jours après sa génération par Fozzels. Cette limite a disparu : vous pouvez maintenant relire et accepter les images quand vous voulez, et elles se synchronisent dès que vous les acceptez.

- Les images qui attendent votre relecture affichent maintenant **Needs your review**. Avant, elles affichaient une icône de chargement qui semblait bloquée.
- Vous avez accepté une image il y a longtemps, mais elle ne s'est pas synchronisée ? Cliquez sur **Actions → Confirm all, Save & Sync** pour la confirmer de nouveau. L'image se synchronise alors immédiatement.
- Nous avons retiré la case **Fully automatic** des Image Flows et des Video Flows, car elle n'envoyait rien à votre boutique. Les images et les vidéos se synchronisent quand vous les acceptez.

## Intégrations

### Akeneo : importer les modèles de produits comme parents

Une nouvelle option de l'intégration Akeneo, **Pull product models as parents**, importe aussi vos modèles de produits Akeneo. Fozzels les affiche comme produits parents au-dessus de leurs variantes.

![Modèles de produits Akeneo comme parents, avec des variantes qui reçoivent le même texte](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/12-akeneo-product-models.png)

Fozzels génère ensuite le contenu une seule fois pour chaque produit parent et l'envoie au modèle de produit dans Akeneo. Toutes les variantes, comme les couleurs et les tailles, le reçoivent automatiquement : vous ne générez donc pas le même texte pour chaque taille.

1. Ouvrez les paramètres de votre intégration Akeneo.
2. Activez **Pull product models as parents**.
3. Exécutez votre Flow sur les produits parents pour écrire un seul texte pour chaque modèle racine.

## Améliorations

### Une nouvelle Daily total batch list

Nous avons repensé la **Daily total batch list**. Elle vous donne maintenant une vue d'ensemble quotidienne claire de tout le contenu que Fozzels génère pour vous.

![La nouvelle Daily total batch list avec les types de contenu, les onglets de statut et les périodes](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/13-daily-total-batch-list.png)

- **Types de contenu** : utilisez le sélecteur à côté du titre pour passer du contenu **Product** au contenu **Category** ou **Blog**.
- **Les statuts en un coup d'œil** : les onglets **All**, **Awaiting sync**, **Synchronized**, **Failed** et **Suspicious** affichent chacun leur propre nombre.
- **Périodes** : sélectionnez **Today**, **7 days**, **30 days** ou une **Custom range** en un clic.
- **Nouveaux boutons** : par exemple, **Review & confirm** se trouve maintenant dans la ligne.
- **Colonne Deleted** : les produits qui ne sont plus dans votre catalogue affichent un badge **Removed from catalog** sous le SKU et une icône de corbeille. Le même filtre **Deleted / Not deleted** est aussi disponible dans vos **Batch lists**.

![Le filtre Deleted dans la Daily total batch list](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/14-deleted-filter.png)

Vos listes restent propres, et les actions groupées sont plus sûres, car vous pouvez facilement exclure les produits retirés.

### Une génération d'images plus fiable

![Grands packshots et avertissements clairs pour les images indisponibles](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/15-image-handling.png)

- **Grands packshots.** Fozzels réduisait déjà les images produit avant de les envoyer à l'IA, mais pas les grandes photos packshot, par exemple une large bande avec de nombreux produits. Beaucoup de boutiques utilisent maintenant de telles photos. Fozzels les réduit donc aussi, à la taille maximale que chaque fournisseur d'IA accepte.
- **Des avertissements clairs quand une image est indisponible.** Si Fozzels ne peut pas télécharger une image produit depuis votre boutique, la ligne affiche une icône d'avertissement, une courte explication, l'adresse de l'image et le code d'erreur. Fozzels réessaie automatiquement et continue la génération quand l'image est de nouveau disponible. Si l'image échoue toujours, Fozzels met en pause la génération pour ce produit.

### Recherche par SKU dans l'Image Completion List

L'**Image Completion List** a maintenant un champ de recherche dans la colonne **SKU**. Saisissez un SKU pour trouver immédiatement l'image dont vous avez besoin, même parmi 1 000 images.

## Corrections

### Un résultat plus propre pour les attributs en texte brut

Pour les attributs sans HTML, Fozzels traitait encore le texte généré comme du Markdown. Des caractères comme les astérisques, les accents graves et les tirets bas pouvaient donc disparaître ou devenir de la mise en forme. Maintenant, les résultats en texte brut gardent chaque caractère exactement comme il est écrit (`2*3 pack`, `snake_case_code`), et Fozzels transforme les balises HTML en texte propre.

![Avant et maintenant : les caractères spéciaux restent dans les résultats en texte brut](/img/kb/fozzels-releases-updates/whats-new-in-fozzels-november-2026-part-1/16-plain-text-output.png)

Créer un Content Flow pour les catégories est pratiquement identique au travail sur les produits : l'interface est familière, pratique et intuitive. Voici un guide pas à pas pour configurer et lancer la génération de contenu pour vos catégories.

## Guide pas à pas

### Étape 1. Accéder aux catégories

Dans le menu latéral, sous **MAIN/CATALOG**, sélectionnez **Categories**.
![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/ma3pY8yLxxW9bLdy8jQZY6oWK-uoZiMiiA.png)

### Étape 2. Sélectionner la vue boutique

En haut de la page, utilisez les filtres du sélecteur de boutique pour vous assurer d'avoir sélectionné la bonne vue boutique.

### ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/1dojt8GKF7WJ4UfUGbaSXAoXnYw-c2EhlQ.png)

### Étape 3. Sélectionner les catégories

Choisissez les catégories pour lesquelles vous souhaitez générer du contenu :

-   **Manuellement :** cochez les cases à côté des catégories souhaitées dans la liste.

-   **Via une action de masse :** sélectionnez **Create Content Flow** dans le menu déroulant `Actions` situé au-dessus du tableau.

> _Remarque :_ l'interface de sélection est identique à celle du workflow produit, ce qui rend le processus rapide et simple.

### ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/IZYD-wiFeEnNG1Ypw6QzBg6w1iNpWI5Ipg.png)
Étape 4. Créer le Flow et configurer les paramètres principaux

1.  Saisissez un **Name** clair pour le flow (par ex. _Description for Mens collection_).

2.  Le champ **Entity Type** sera déjà présélectionné sur `Category`.

###
Étape 5. Choisir l'attribut cible

Sélectionnez l'attribut de catégorie pour lequel vous souhaitez générer du contenu (par ex. `Description`) dans la liste déroulante **Attribute**, puis enregistrez votre sélection.

> **Que faire si l'attribut requis ne figure pas dans la liste ?**
>
> 1.  Accédez à **Integrations** (menu de gauche) → onglet **Attributes**.
>
> 2.  Sélectionnez **Entity Type** → `Category`.
>     ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/8MMJXlxfi3GgqtgxIQfI_XZ5F1VbdlhHtA.png)
>
> 3.  Recherchez l'attribut requis dans la liste.
>
> 4.  Vérifiez la propriété **Mutable** : si elle est désactivée, activez-la pour autoriser les mises à jour de contenu pour cet attribut.
>     ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/wF2PLUJw__aF3ktzhc2gqAQN6hQeKV-Cew.png)
>

Étape 6. Configuration de l'IA, prompt et lancement

1.  Choisissez le modèle d'IA de votre choix.

2.  Appliquez des filtres supplémentaires si nécessaire.

3.  Saisissez votre **Prompt**.

4.   Ajoutez les paramètres d'automatisation.

5.  Activez votre flow.

6.  Enregistrez le flow.

7.  Cliquez sur **Run Now** pour lancer la génération.

## Informations complémentaires

Toutes les fonctionnalités et tous les mécanismes associés fonctionnent **exactement comme pour les flows produits** :

-   **Daily Total Batch List :** les résultats de génération de vos catégories sont également affichés dans le rapport quotidien général.

-   **Batch Lists** et règles générales de génération.

-   Automatisation et export/import de données.

-   Mise en forme, mots interdits / expressions suspectes.

-   Balises HTML autorisées et mécanismes de chevauchement.

Bonne génération !

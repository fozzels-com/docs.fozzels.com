Das Erstellen eines Content Flows für Kategorien ist praktisch identisch mit der Arbeit mit Produkten – die Benutzeroberfläche ist vertraut, komfortabel und intuitiv. Nachfolgend finden Sie eine Schritt-für-Schritt-Anleitung, wie Sie die Content-Generierung für Ihre Kategorien einrichten und starten.

## Schritt-für-Schritt-Anleitung

### Schritt 1. Zu den Kategorien navigieren

Wählen Sie im Seitenmenü unter **MAIN/CATALOG** den Punkt **Categories**.
![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/ma3pY8yLxxW9bLdy8jQZY6oWK-uoZiMiiA.png)

### Schritt 2. Die Store View auswählen

Verwenden Sie oben auf der Seite die Store-Switcher-Filter, um sicherzustellen, dass Sie die richtige Store View ausgewählt haben.

### ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/1dojt8GKF7WJ4UfUGbaSXAoXnYw-c2EhlQ.png)

### Schritt 3. Kategorien auswählen

Wählen Sie die Kategorien aus, für die Sie Inhalte generieren möchten:

-   **Manuell:** Aktivieren Sie die Kontrollkästchen neben den gewünschten Kategorien in der Liste.

-   **Über Mass Action:** Wählen Sie **Create Content Flow** aus dem Dropdown-Menü `Actions` oberhalb der Tabelle.

> _Hinweis:_ Die Auswahloberfläche ist identisch mit dem Produkt-Workflow, was den Prozess schnell und einfach macht.

### ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/IZYD-wiFeEnNG1Ypw6QzBg6w1iNpWI5Ipg.png)
Schritt 4. Den Flow erstellen und die Haupteinstellungen konfigurieren

1.  Geben Sie einen eindeutigen **Namen** für den Flow ein (z. B. _Description for Mens collection_).

2.  Das Feld **Entity Type** ist bereits als `Category` vorausgewählt.

###
Schritt 5. Das Ziel-Attribut auswählen

Wählen Sie im Dropdown-Menü **Attribute** das Kategorie-Attribut aus, für das Sie Inhalte generieren möchten (z. B. `Description`), und speichern Sie Ihre Auswahl.

> **Was ist, wenn das erforderliche Attribut nicht in der Liste enthalten ist?**
>
> 1.  Gehen Sie zu **Integrations** (linkes Menü) → Registerkarte **Attributes**.
>
> 2.  Wählen Sie **Entity Type** → `Category`.
>     ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/8MMJXlxfi3GgqtgxIQfI_XZ5F1VbdlhHtA.png)
>
> 3.  Suchen Sie das erforderliche Attribut in der Liste.
>
> 4.  Prüfen Sie die Eigenschaft **Mutable**: Ist sie deaktiviert, schalten Sie sie ein, um Inhaltsaktualisierungen für dieses Attribut zu erlauben.
>     ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/wF2PLUJw__aF3ktzhc2gqAQN6hQeKV-Cew.png)
>

Schritt 6. AI Configuration, Prompt und Start

1.  Wählen Sie Ihr bevorzugtes KI-Modell.

2.  Wenden Sie bei Bedarf zusätzliche Filter an.

3.  Geben Sie Ihren **Prompt** ein.

4.   Fügen Sie Automatisierungseinstellungen hinzu.

5.  Aktivieren Sie Ihren Flow.

6.  Speichern Sie den Flow.

7.  Klicken Sie auf **Run Now**, um die Generierung zu starten.

## Zusätzliche Informationen

Alle begleitenden Funktionen und Mechaniken funktionieren **genau wie bei Produkt-Flows**:

-   **Daily Total Batch List:** Die Ergebnisse Ihrer Kategorie-Generierung werden ebenfalls im allgemeinen Tagesbericht angezeigt.

-   **Batch Lists** und allgemeine Generierungsregeln.

-   Automatisierung sowie Datenexport/-import.

-   Formatierung, Stoppwörter / verdächtige Ausdrücke.

-   Erlaubte HTML-Tags und Overlapping-Mechaniken.

Viel Erfolg beim Generieren!

## Wie synchronisiere ich generierte Bilder zu meinem Webshop?

Genehmigen Sie das Bild → halten Sie die Maus darunter und wählen Sie **Synchronize** → warten Sie auf den Zeitstempel „Synchronized At" → überprüfen Sie die Ergebnisse auf Ihrer Website.

## Das Laden von Symbolen wird stundenlang angezeigt, während die Bilder synchronisiert werden.

Synchronisierung ist nicht sofort. Falls der Ladespeicher 30+ Minuten anhält, kontaktieren Sie den Support. Stellen Sie sicher, dass Sie beide Schritte Genehmigung und Synchronisierung abgeschlossen haben.

## Wie erstelle ich einen Single-Image-Flow (nur oben / nur unten)?

Erstellen Sie einen neuen Image-Flow, wählen Sie den Typ „Single image" und wählen Sie ein Produkt. Nur dieses Element wird verwendet.

## Mein Image-Flow funktioniert nicht / ich erhalte einen Modellfehler.

KI-Modellanbieter aktualisieren möglicherweise ihre Spezifikationen. Versuchen Sie, zu einem alternativen Modell zu wechseln (z. B. Gemini 3 Pro, GPT Image 1). Das Team wird aktualisiert, wenn das Modell wieder funktioniert.

## Wie aktiviere und bestätige ich einen Image-Flow?

Stellen Sie sicher, dass Ihr Flow sowohl aktiviert (Seite 1) als auch bestätigt (Seite 2) ist. Beide Schritte sind erforderlich.

## Kann Fozzels Hintergründe von Produktbildern entfernen?

Ja, Fozzels kann KI-basierte Hintergrundentfernung durchführen. Für einige PIMs wird das Verschieben bearbeiteter Bilder nicht unterstützt – manueller Download ist verfügbar.

## Kann ich KI-generierte Bilder zu meinem PIM verschieben?

Nicht alle PIMs unterstützen das Bild-Push über API. Einige Integrationen (Shopify, Shopware) unterstützen es. Manueller Download ist immer verfügbar.

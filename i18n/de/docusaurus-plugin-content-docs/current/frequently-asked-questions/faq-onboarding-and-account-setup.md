## Wie richte ich ein neues Fozzels-Konto mit einer PIM-Verbindung ein?

Um ein neues Konto mit einer PIM-Verbindung (z. B. Katana) einzurichten, geben Sie folgende Informationen an: die E-Mail-Adresse des Benutzers und den PIM-API-Schlüssel. Das Fozzels-Team erstellt das Konto, richtet die Verbindung ein und sendet die Anmeldedaten an den Benutzer.

## Wie verbinde ich meinen Magento-Shop mit Fozzels?

Kontaktieren Sie das Fozzels-Team und geben Sie folgende Informationen an: die Shop-URL, die E-Mail-Adresse für das Benutzerkonto und geben Sie an, ob Sie ein Test- oder bezahltes Konto benötigen. Das Team richtet die Verbindung ein und erstellt das Konto mit Anmeldedaten.

## Kann ich ein Testkonto für Fozzels bekommen?

Ja, Fozzels bietet eine kostenlose 14-Tage-Testversion. Während der Testversion bezahlen Sie keine Lizenzgebühr, Sie zahlen jedoch für die Nutzung von KI-Tokens. Verbinden Sie Ihre Kreditkarte in den Kontoeinstellungen. Das Team richtet Ihre Integration ein und erstellt initiale Prompts.

## Wie funktioniert die kostenlose Testversion von Fozzels?

14-Tage-Testversion, keine Lizenzgebühr, aber KI-Token-Kosten fallen an. Eine Kreditkarte ist erforderlich. Das Team richtet Ihre Integration ein, erstellt initiale Prompts und kann einen Anruf einplanen, um Sie durch alles zu führen.

## Wie verbinde ich meinen Shopware 6-Shop mit Fozzels?

Geben Sie dem Fozzels-Team Ihren Access Key ID und Secure Access Key aus dem Shopware-Admin-Panel. Für einen detaillierten Leitfaden siehe den Shopware-Integrations-Artikel.

## Wie erstelle ich einen API-Schlüssel in Shopware 6 für Fozzels?

Gehen Sie im Shopware-Admin zu Settings → System → Integrations und erstellen Sie eine neue Integration, die einen Access Key ID und Secret Access Key generiert. Verwenden Sie den Integration-Schlüssel (beginnt mit `SWIA...`), nicht den Sales Channel-Schlüssel.

## Wie verbinde ich meinen Shopify-Shop mit Fozzels (Aktualisierung 2026)?

Nach den jüngsten Shopify-Änderungen muss der Shop-Inhaber eine benutzerdefinierte App über das Shopify DEV Dashboard erstellen. Folgen Sie dem Leitfaden und geben Sie dann folgende Informationen an: Shop-URL, API-Schlüssel, API-Geheimnis, App-Host-Name und ob Sie Markets oder LangShop verwenden.

## Welche Informationen benötigt Fozzels von mir, um eine Shopify-Integration einzurichten?

Sie benötigen: Shop-URL, API-Schlüssel, API-Geheimnis, App-Host-Name und ob Sie Markets oder LangShop verbinden möchten. Der Shop-Inhaber erstellt eine benutzerdefinierte App über das Shopify DEV Dashboard.

## Warum kann ich die Shopify-Integration mit Mitarbeiterzugriff nicht abschließen?

Shopify erfordert, dass der Shop-Inhaber spezifische Einstellungen im Dev Dashboard vornimmt. Das Fozzels-Team kann einen 20-Minuten-Google-Meet-Anruf einplanen, um den Shop-Inhaber durch die Schritte zu führen.

## Wie verbinde ich meinen Lightspeed-Shop mit Fozzels?

Erstellen Sie einen API-Schlüssel in Lightspeed (mit Produktbearbeitungsberechtigung) und senden Sie dann den API-Schlüssel und das API-Geheimnis an das Fozzels-Team.

## Kann Fozzels mit Akeneo PIM integrieren?

Ja, Fozzels kann eine Integration mit Akeneo PIM aufbauen. Ein benutzerdefiniertes Textfeld kann in Akeneo erstellt werden, in das Fozzels Inhalte schreibt. Kontaktieren Sie das Team, um die Einrichtung zu besprechen.

## Wie füge ich neue Websites zu meinem Fozzels-Konto hinzu?

Erstellen Sie eine neue Integration in Fozzels mit eindeutigen API-Schlüsseln für jede Website. Jede Website benötigt ihre eigenen API-Anmeldedaten – Sie können Schlüssel von einer anderen Website nicht wiederverwenden.

## Kann ich mehrere Benutzerkonten für mein Team einrichten?

Ja, Fozzels unterstützt mehrere Benutzerkonten pro Shop mit unterschiedlichen Zugriffsstufen (z. B. Manager-Zugriff über mehrere Shops hinweg). Kontaktieren Sie den Support, um zusätzliche Konten einzurichten.

## Können mehrere Benutzer ein Fozzels-Konto teilen?

Teilen Sie keine Anmeldedaten. Jeder Kollege sollte ein eigenes Konto erhalten: Ein Reseller kann eine Einladung senden, und der eingeladene Benutzer legt sein eigenes Passwort fest. Den vollständigen Ablauf finden Sie unter [Team Access Management: Fozzels Roles Guide (Customer vs. Reseller)](/account-core-resources/team-access-management-fozzels-roles-guide-customer-vs-reseller). Für einige Pläne können separate Konten mit Manager-Zugriff erstellt werden – wenden Sie sich an den Support.

## Was sind die Fozzels-Abonnementpläne?

Die Pläne reichen von Basic Light (€299/Monat) bis Unlimited (€999/Monat), alle monatlich kündbar. Höhere Pläne bieten mehr tägliche Generierungslimits, Prompt-Flexibilität und Funktionen zur Bild-/Videogenerierung.

## Wie wähle ich nach der Einrichtung einen Abonnementplan?

Melden Sie sich an, gehen Sie zum Abschnitt „Upgrade your account" und wählen Sie Ihren Plan. Kontaktieren Sie den Support für Anleitung.

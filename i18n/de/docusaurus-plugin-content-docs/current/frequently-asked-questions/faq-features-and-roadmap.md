## Kann ich einen benutzerdefinierten Produktabruf-Zeitplan einstellen?

Ja. Seit Release 5.14 können Sie eine bequeme Zeit sowohl auf Integrations- als auch auf Shop-Ebene einstellen.

## Kann ich die Liste verdächtiger Inhalte anpassen?

Ja – passen Sie die Liste verdächtiger Wörter an Ihre Vorlieben an.

## Kann ich YouTube-Videos in generierten Inhalten einbetten?

Sie können iFrame-Anweisungen zu Ihrem Prompt hinzufügen, aber Fozzels kann iFrame-Tags aus Sicherheitsgründen filtern. Kontaktieren Sie den Support, um dies zu besprechen.

## Kann Fozzels Inhalte für Kategorieseiten generieren?

Ja. Die Generierung von Kategorieinhalten ist verfügbar – siehe [How to Create a Content Flow for Categories in Fozzels](/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels).

## Kann Fozzels Merchant-Feed-Felder (Geschlecht, Farbe, MPN) verwalten?

Möglicherweise ja, abhängig von Ihrer Plattform. Kontaktieren Sie den Support mit Details zu Ihrem Setup.

## Gibt es Benachrichtigungen für fehlgeschlagene Importe oder Fehler?

Dies ist eine Feature-Anfrage, die das Team kennt. Überwachen Sie vorerst über das Dashboard. Kontaktieren Sie den Support für proaktive Hilfe.

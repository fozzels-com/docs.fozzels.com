## Ich habe einen Flow versehentlich als veraltet gekennzeichnet. Kann ich das rückgängig machen?

Kontaktieren Sie den Support – Sie können den Flow reaktivieren, ohne eine vollständige Neugenerierung auszulösen.

## Was macht die Schaltfläche „Obsolete"?

Sie deaktiviert den Flow. Sie generiert keinen Inhalt automatisch neu. Der Support kann ihn bei Bedarf reaktivieren.

## Wie füge ich Produkte von einer bestimmten Marke zu einem Flow hinzu?

In Flow-Einstellungen → Filter → fügen Sie einen Brand-Filter hinzu → verwenden Sie den Operator **IN**, um die Marke einzuschließen.

## Wie aktiviere ich einen Flow?

Aktivieren Sie ihn nach der Erstellung des Flow in den Flow-Einstellungen. Kontaktieren Sie den Support, wenn Sie sich nicht sicher sind.

## Wie dupliziere ich Flows für mehrere Shops/Domains?

Klicken Sie auf das Menü mit drei Punkten → **Duplicate** → wählen Sie den Ziel-Shop → passen Sie Namen, Modell, Sprache und Links an → Speichern.

## Kann ich die Batch-Listen von veralteten Flows ansehen?

Ja, sollte möglich sein. Falls das Klicken nicht funktioniert, kann es ein bereits behobener Bug sein – kontaktieren Sie den Support.

## Sollte ich Flows bei Verbindungsproblemen pausieren?

Ja. Das Aussetzen von Flows verhindert unnötige Fehler und Token-Nutzung. Reaktivieren Sie sie, nachdem der Support die Wiederherstellung der Verbindung bestätigt.

## Kann ich automatisch generierte Inhalte rückgängig machen (Undo Sync)?

Es gibt kein automatisches Rückgängigmachen. Duplizieren Sie den Flow mit einem korrigierten Prompt und führen Sie ihn erneut aus, oder kontaktieren Sie den Support zur Unterstützung beim Zurücksetzen.

Hemos combinado dos actualizaciones importantes para hacer tu flujo de trabajo de contenidos más confiable y tus capacidades de sincronización ilimitadas.

##  Globalización y excelencia SEO

-   **Localización de Metafields de Shopify (v5.16):** Ahora puedes generar y sincronizar **Metafields** basados en texto para **Shopify Markets** y **Langshop**. Esto cubre tanto tiendas predeterminadas como traducciones de idiomas adicionales.

-   **Corrección: restablecimiento de título meta SEO (v5.15):** Hemos resuelto un problema donde los títulos meta podrían restablecerse a sus valores originales. Tus títulos SEO optimizados ahora se guardan de forma segura en todos los mercados e idiomas.

-   **Protección SEO de Shopify (v5.16):** Para evitar inconsistencias de datos, el sistema ahora restringe la sincronización de campos SEO estándar para tiendas no predeterminadas (debido a la arquitectura de la API de Shopify).

-   **Cumplimiento de la API de Shopify:** Nuestras aplicaciones se han actualizado completamente para cumplir con los últimos requisitos de Shopify. **Nota:** Si recibiste un correo electrónico sobre el plazo del **1 de abril de 2026**, no te preocupes, ya lo hemos manejado. Todo está configurado para un funcionamiento estable.

##
WooCommerce: diagnósticos inteligentes (v5.16)

La configuración de la integración ahora es transparente e infalible:

-   **Diagnósticos de conexión:** Verificación automática de credenciales de API y permisos cada vez que guardas.

-   **Verificación de estado del complemento:** Fozzels ahora detecta si **ACF, Yoast SEO, AIOSEO o WPML** están activos y configurados correctamente.

-   **Detección de conflictos:** El sistema te advierte si hay múltiples complementos SEO activos simultáneamente para evitar errores de sincronización.

-   **Alertas de conector obsoleto:** Recibe notificaciones si tu complemento conector de Fozzels necesita una actualización, con un enlace de descarga directo proporcionado.

## Interfaz y eficiencia (v5.15 y v5.16)

-   **Filtros en línea (v5.15):** La **lista de finalización de contenido** ahora tiene filtrado en línea. Puedes buscar y ordenar productos directamente dentro de columnas específicas, no solo por atributo objetivo.
    ![](/img/kb/fozzels-releases-updates/release-5-15-5-16-stability-globalization-and-intelligent-control/2uzvcc8k7RbyCI06htFACyS1d5T-DvpDzw.png)

-   **Actualización del informe diario (v5.16):** Se agregó un botón **Actualizar** manual e un **intervalo de actualización automática** personalizable (por ejemplo, cada 3s, 5s o 10s). Perfecto para monitoreo en tiempo real de lotes grandes.
    ![](/img/kb/fozzels-releases-updates/release-5-15-5-16-stability-globalization-and-intelligent-control/EPrxpwS-4GTE8JJhyvJeGbJbwMGyQWg2XA.png)

-   **Precisión del estado del flujo (v5.15):** Se corrigieron los indicadores de estado en la lista de flujos. Los recuentos de "Generado/Sincronizado" ahora reflejan con precisión el estado real de tus productos.

## Potencia de IA y calidad de contenido (v5.16)

-   **Soporte para GPT 5.4:** Se integró el modelo de IA más reciente y rápido para calidad de contenido de primer nivel.

![](/img/kb/fozzels-releases-updates/release-5-15-5-16-stability-globalization-and-intelligent-control/CwyidVIOLNA1iTY-O0gNEvKRWqvByuuTUQ.png)

-   **Modo de descubrimiento mejorado:** Nuestra función "Pruébalo" ahora está impulsada por **Claude**, utilizando indicaciones expandidas para ofrecer descripciones de muestra profundas, estructuradas y de alta calidad.

-   **Opciones de finalización avanzadas:** Cada generación guardada ahora almacena su "pasaporte técnico" completo: todas las propiedades y configuraciones utilizadas para ese resultado específico están disponibles para revisar.

## Estabilidad del sistema y rendimiento (v5.16)

-   **Corrección de estabilidad del flujo (ventana de 20 h):** Hemos optimizado el intervalo para ejecutar nuevamente flujos de 24 a **20 horas**. Esto garantiza que incluso con ligeros cambios en el cronograma de extracción, tus generaciones diarias nunca se omitirán.
    ![](/img/kb/fozzels-releases-updates/release-5-15-5-16-stability-globalization-and-intelligent-control/vYY-ckKhQ_LBeofBs8lAf_VF20AYWDTR3A.png)

-   **Correcciones de flujo de imagen:** Se mejoró la estabilidad del procesamiento de imágenes y las transferencias entre Fozzels y tu tienda.

## Marqué accidentalmente un flujo como obsoleto. ¿Puedo deshacer esto?

Póngase en contacto con el soporte — pueden reactivar el flujo sin desencadenar regeneración completa.

## ¿Qué hace el botón "Obsolete"?

Desactiva el flujo. No regenera contenido automáticamente. El soporte puede reactivarlo si es necesario.

## ¿Cómo agrego productos de una marca específica a un flujo?

En configuración de flujo → Filtros → agregue un filtro de marca → use el operador **IN** para incluir la marca.

## ¿Cómo activo un flujo?

Después de crear un flujo, actívelo en la configuración del flujo. Póngase en contacto con el soporte si no está seguro.

## ¿Cómo duplico flujos para múltiples tiendas/dominios?

Haga clic en el menú de tres puntos → **Duplicate** → seleccione la tienda de destino → ajuste nombre, modelo, idioma y enlaces → Guardar.

## ¿Puedo ver las listas de lotes de flujos obsoletos?

Sí, debería poder verlos. Si hacer clic no funciona, puede ser un error ya corregido — póngase en contacto con el soporte.

## ¿Debo pausar flujos durante problemas de conexión?

Sí. Suspender flujos evita errores innecesarios y uso de tokens. Reactívelos después de que el soporte confirme que la conexión se restauró.

## ¿Puedo revertir contenido generado automáticamente (deshacer sincronización)?

No hay deshacer automático. Duplique el flujo con una indicación corregida y ejecútelo nuevamente, o póngase en contacto con el soporte para ayudar a reiniciar.

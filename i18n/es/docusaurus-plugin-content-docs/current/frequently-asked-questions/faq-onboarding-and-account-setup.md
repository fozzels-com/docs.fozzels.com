## ¿Cómo configuro una nueva cuenta de Fozzels con una conexión PIM?

Para configurar una nueva cuenta con una conexión PIM (por ejemplo, Katana), proporcione: la dirección de correo electrónico del usuario y la clave API del PIM. El equipo de Fozzels creará la cuenta, configurará la conexión y enviará las credenciales de inicio de sesión al usuario.

## ¿Cómo conecto mi tienda Magento a Fozzels?

Póngase en contacto con el equipo de Fozzels y proporcione: la URL de la tienda, la dirección de correo electrónico para la cuenta de usuario y especifique si necesita una cuenta de prueba o de pago. El equipo configurará la conexión y creará la cuenta con credenciales de inicio de sesión.

## ¿Puedo obtener una cuenta de prueba de Fozzels?

Sí, Fozzels ofrece una prueba gratuita de 14 días. Durante la prueba no paga por la licencia, pero sí paga por el uso de tokens de IA. Conecte su tarjeta de crédito en la configuración de la cuenta. El equipo configurará su integración y creará indicaciones iniciales.

## ¿Cómo funciona la prueba gratuita de Fozzels?

Prueba gratuita de 14 días, sin tarifa de licencia pero se aplican costos de tokens de IA. Se requiere una tarjeta de crédito. El equipo configura su integración, crea indicaciones iniciales y puede programar una llamada para guiarle a través de todo.

## ¿Cómo conecto mi tienda Shopware 6 a Fozzels?

Proporcione al equipo de Fozzels su ID de Clave de Acceso y Clave de Acceso Seguro del panel de administración de Shopware. Para obtener una guía detallada, consulte el artículo de integración de Shopware.

## ¿Cómo creo una clave API en Shopware 6 para Fozzels?

En el panel de administración de Shopware vaya a Configuración → Sistema → Integraciones y cree una nueva Integración, que genera un ID de Clave de Acceso y una Clave de Acceso Secreto. Use la clave de Integración (comienza con `SWIA...`), no la clave del Canal de Ventas.

## ¿Cómo conecto mi tienda Shopify a Fozzels (actualización 2026)?

Debido a los cambios recientes de Shopify, el propietario de la tienda debe crear una Aplicación personalizada a través del Panel DEV de Shopify. Siga la guía y luego proporcione: URL de la Tienda, Clave API, Secreto API, Nombre de Host de la Aplicación y si utiliza Markets o LangShop.

## ¿Qué información necesita Fozzels de mí para configurar una integración de Shopify?

Necesita: URL de la Tienda, Clave API, Secreto API, Nombre de Host de la Aplicación y si planea conectar Markets o LangShop. El propietario de la tienda crea una Aplicación personalizada a través del Panel DEV de Shopify.

## ¿Por qué no puedo completar la integración de Shopify con acceso de colaborador?

Shopify requiere que el Propietario de la Tienda aplique configuraciones específicas en el Panel Dev. El equipo de Fozzels puede programar una llamada de Google Meet de 20 minutos para guiar al Propietario de la Tienda a través de los pasos.

## ¿Cómo conecto mi tienda Lightspeed a Fozzels?

Cree una clave API en Lightspeed (otorgue permiso de edición de producto) y luego envíe la Clave API y el Secreto API al equipo de Fozzels.

## ¿Puede Fozzels integrarse con PIM Akeneo?

Sí, Fozzels puede construir una integración con PIM Akeneo. Se puede crear un campo de texto personalizado en Akeneo donde Fozzels escribe contenido. Póngase en contacto con el equipo para discutir la configuración.

## ¿Cómo agrego nuevos sitios web a mi cuenta de Fozzels?

Cree una nueva integración en Fozzels con claves API únicas para cada sitio web. Cada sitio necesita sus propias credenciales API — no puede reutilizar claves de otro sitio.

## ¿Puedo configurar múltiples cuentas de usuario para mi equipo?

Sí, Fozzels admite múltiples cuentas de usuario por tienda con diferentes niveles de acceso (por ejemplo, acceso de gerente en múltiples tiendas). Póngase en contacto con el soporte para configurar cuentas adicionales.

## ¿Pueden varios usuarios compartir una cuenta de Fozzels?

No comparta credenciales de inicio de sesión. Cada compañero debe tener su propia cuenta: un Reseller puede enviar una invitación y el usuario invitado establece su propia contraseña. Consulte [Team Access Management: Fozzels Roles Guide (Customer vs. Reseller)](/account-core-resources/team-access-management-fozzels-roles-guide-customer-vs-reseller) para el proceso completo. Para algunos planes se pueden crear cuentas separadas con acceso de gerente — póngase en contacto con el soporte.

## ¿Cuáles son los planes de suscripción de Fozzels?

Los planes van desde Basic Light (€299/mes) hasta Unlimited (€999/mes), todos cancelables mensualmente. Los planes superiores ofrecen límites de generación diaria más altos, mayor flexibilidad de indicaciones y capacidades de generación de imágenes/vídeo.

## ¿Cómo elijo un plan de suscripción después de la configuración?

Después de iniciar sesión, vaya a la sección "Actualice su cuenta" y seleccione su plan. Póngase en contacto con el soporte para obtener orientación.

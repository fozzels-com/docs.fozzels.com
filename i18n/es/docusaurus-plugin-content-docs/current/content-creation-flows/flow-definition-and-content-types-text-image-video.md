## Descripción General del Concepto

Un Flujo es un concepto fundamental en Fozzels. Es un proceso automatizado de múltiples pasos personalizado que aprovecha las capacidades de IA para transformar datos de entrada (su catálogo de productos) en elementos de contenido listos para usar, de alta calidad y dirigidos (texto, imágenes, video) con intervención humana mínima.

## Rol y Propósito de un Flujo

Un Flujo sirve para garantizar la generación de contenido escalable, controlada y consistente dentro de su tienda en línea.

1.  **Automatice** la creación de grandes volúmenes de descripciones, meta-etiquetas, imágenes o videos.

2.  **Garantice** la consistencia de estilo y tono en diferentes grupos de productos.

3.  **Controle** el presupuesto definiendo claramente qué productos y con qué frecuencia se generará el contenido.

4.  **Sincronice** contenido terminado directamente en su tienda integrada (Shopify, Magento, Next Chapter, etc.).

## Componentes Clave de un Flujo

Cada Flujo consiste en partes lógicas que usted configura:

### 1. Selección de Producto

1.  **Defina** el grupo objetivo de productos para procesamiento.

2.  **Utilice** el poderoso sistema de filtrado para seleccionar productos por categoría, color, SKU o estado.

3.  **Lea** más sobre filtrado avanzado de productos [aquí](/data-import-and-quality/product-filtering-for-content-generation/).

4.  **Resultado:** Solo los productos seleccionados serán pasados a la siguiente etapa.

### 2. Instrucción de IA (Indicación)

1.  **Escriba** o **cargue** instrucciones detalladas para la IA (la indicación).

2.  **Utilice** bloques de atributos dinámicos para que la IA pueda adaptar el contenido a características específicas del producto (por ejemplo, color, tamaño). **Lea** más sobre atributos y su configuración [aquí](/data-import-and-quality/attribute-quality-analysis-data-density-percent-custom-attributes/).

3.  **Defina** el estilo, tono, idioma y límites de texto requeridos (por ejemplo, conteo máximo de tokens).

### 3. Configuración Adicional y Control

1.  **Protección contra Duplicados:** **Active** la función **Prevenir generación de contenido superpuesto** para evitar generación de contenido redundante para un atributo que ya ha sido procesado. **Lea** más sobre prevención de generación superpuesta [aquí](/content-creation-flows/prevent-overlapping-content-generation-function-global-prevent-function/).

2.  **Optimización de Imagen:** Cuando trabaje con imágenes, **utilice** la función **Cambio de Tamaño de Imagen** para optimización automática de archivos grandes. **Lea** más sobre la función Cambio de Tamaño de Imagen [aquí](/content-creation-flows/ai-configuration-image-optimization-resize-rationale-and-implementation/).

### 4. Automatización

1.  **Configure** el horario de lanzamiento del Flujo (por ejemplo, diario, semanal).

2.  **Establezca** límites de generación (número de productos por ejecución).

3.  **Defina** reglas de sincronización (enviar contenido automáticamente al sitio web o esperar confirmación manual).

## Tipos de Flujos en Fozzels

Fozzels soporta tres tipos principales de flujos, cada uno dirigido a un tipo específico de contenido:

### 3.1. Flujo de Contenido

1.  **Propósito:** Generación de contenido de texto (descripciones de productos, descripciones cortas, meta-etiquetas, textos SEO).

2.  **Objetivo:** Actualización de un atributo de producto específico.

### 3.2. Flujo de Imagen

1.  **Propósito:** Generación de imágenes de alta calidad (modelos fotográficos, escenas, combinaciones de productos).

2.  **Objetivo:** Creación de materiales visuales únicos que se sincronicen como nuevas imágenes de productos.

### 3.3. Flujo de Video

1.  **Propósito:** Generación de contenido de video.

2.  **Objetivo:** Creación de materiales dinámicos para promoción de productos.

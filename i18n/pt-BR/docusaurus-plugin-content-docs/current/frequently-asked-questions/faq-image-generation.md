## Como sincronizo imagens geradas para meu webshop?

Aprove a imagem → passe o mouse e selecione **Synchronize** → espere pelo timestamp "Synchronized At" → verifique os resultados em seu website.

## Ícones de carregamento mostram por horas durante sincronização de imagem.

Sincronização não é instantânea. Se o estado de carregamento persiste por 30+ minutos, entre em contato com o suporte. Garanta que você completou ambos os passos de aprovação e sincronização.

## Como crio um flow de imagem única (apenas topo / apenas fundo)?

Crie um novo flow de imagem, selecione o tipo "Single image" e escolha um produto. Apenas aquele item será usado.

## Meu flow de imagem não está funcionando / Obtenho um erro de modelo.

Provedores de modelo de IA podem atualizar suas especificações. Tente mudar para um modelo alternativo (por exemplo, Gemini 3 Pro, GPT Image 1). O time atualizará quando o modelo estiver de volta.

## Como ativo e confirmo um flow de imagem?

Garanta que seu flow está tanto ativado (página 1) quanto confirmado (página 2). Ambos os passos são necessários.

## Fozzels pode remover fundos de imagens de produto?

Sim, Fozzels pode fazer remoção de fundo baseada em IA. Para alguns PIMs, enviar imagens editadas de volta não é suportado — download manual está disponível.

## Posso enviar imagens geradas por IA para meu PIM?

Nem todos os PIMs suportam envio de imagem via API. Algumas integrações (Shopify, Shopware) suportam. Download manual está sempre disponível.

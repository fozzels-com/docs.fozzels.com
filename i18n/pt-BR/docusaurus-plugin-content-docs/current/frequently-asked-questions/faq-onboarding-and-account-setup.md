## Como configuro uma nova conta Fozzels com uma conexão PIM?

Para configurar uma nova conta com uma conexão PIM (por exemplo, Katana), forneça: o endereço de email do usuário e a chave da API do PIM. O time Fozzels criará a conta, configurará a conexão e enviará as credenciais de login para o usuário.

## Como conecto minha loja Magento ao Fozzels?

Entre em contato com o time Fozzels e forneça: a URL da loja, o endereço de email para a conta de usuário e especifique se você precisa de uma conta de teste ou paga. O time configurará a conexão e criará a conta com credenciais de login.

## Posso conseguir uma conta de teste para Fozzels?

Sim, Fozzels oferece um teste gratuito de 14 dias. Durante o teste você não paga a licença, mas paga pelo uso de tokens de IA. Conecte seu cartão de crédito nas configurações de conta. O time configurará sua integração e criará prompts iniciais.

## Como funciona o teste gratuito Fozzels?

Teste gratuito de 14 dias, sem taxa de licença, mas custos de tokens de IA se aplicam. Um cartão de crédito é necessário. O time configura sua integração, cria prompts iniciais e pode agendar uma chamada para guiá-lo por tudo.

## Como conecto minha loja Shopware 6 ao Fozzels?

Forneça ao time Fozzels seu Access Key ID e Secure Access Key do painel de admin Shopware. Para um guia detalhado, consulte o artigo de integração Shopware.

## Como crio uma chave de API em Shopware 6 para Fozzels?

No admin Shopware vá para Settings → System → Integrations e crie uma nova Integration, que gera um Access Key ID e Secret Access Key. Use a chave Integration (começa com `SWIA...`), não a chave Sales Channel.

## Como conecto minha loja Shopify ao Fozzels (atualização 2026)?

Desde as mudanças recentes do Shopify, o dono da loja deve criar um App customizado via Shopify DEV Dashboard. Siga o guia e forneça: Store URL, API Key, API Secret, App Host Name e se usa Markets ou LangShop.

## Que informações Fozzels precisa de mim para configurar uma integração Shopify?

Você precisa de: Store URL, API Key, API Secret, App Host Name e se pretende conectar Markets ou LangShop. O dono da loja cria um App customizado via Shopify DEV Dashboard.

## Por que não consigo completar a integração Shopify com acesso de colaborador?

Shopify exige que o Store Owner aplique configurações específicas no Dev Dashboard. O time Fozzels pode agendar uma chamada de 20 minutos no Google Meet para guiar o Store Owner pelos passos.

## Como conecto minha loja Lightspeed ao Fozzels?

Crie uma chave de API em Lightspeed (conceda permissão de edição de produto) e envie o API Key e API Secret para o time Fozzels.

## Fozzels pode integrar com Akeneo PIM?

Sim, Fozzels pode construir uma integração com Akeneo PIM. Um campo de texto customizado pode ser criado em Akeneo onde Fozzels escreve conteúdo. Entre em contato com o time para discutir a configuração.

## Como adiciono novos websites à minha conta Fozzels?

Crie uma nova integração em Fozzels com chaves de API únicas para cada website. Cada site precisa de suas próprias credenciais de API — você não pode reutilizar chaves de outro site.

## Posso configurar múltiplas contas de usuário para meu time?

Sim, Fozzels suporta múltiplas contas de usuário por loja com diferentes níveis de acesso (por exemplo, acesso de gerente em múltiplas lojas). Entre em contato com o suporte para configurar contas adicionais.

## Múltiplos usuários podem compartilhar uma conta Fozzels?

Não compartilhe credenciais de login. Cada colega deve ter a própria conta: um Reseller pode enviar um convite, e o usuário convidado define a própria senha. Veja [Team Access Management: Fozzels Roles Guide (Customer vs. Reseller)](/account-core-resources/team-access-management-fozzels-roles-guide-customer-vs-reseller) para o fluxo completo. Para alguns planos, contas separadas com acesso de gerente podem ser criadas — entre em contato com o suporte.

## Quais são os planos de subscrição Fozzels?

Os planos variam de Basic Light (€299/mês) até Unlimited (€999/mês), todos canceláveis mensalmente. Planos maiores oferecem limites de geração diária maiores, flexibilidade de prompts e capacidades de geração de imagem e vídeo.

## Como escolho um plano de subscrição após a configuração?

Após fazer login, vá para a seção "Upgrade your account" e selecione seu plano. Entre em contato com o suporte para orientação.

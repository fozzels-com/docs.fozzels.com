A **Visualização Detalhada do Produto** oferece uma interface dedicada e consolidada para revisar todos os metadados associados a um único produto. Este recurso foi projetado para eliminar a complexidade do Catálogo principal, onde alguns atributos poderiam estar ocultos ou a estrutura da tabela ser muito incômoda para referência rápida.
A Visualização Detalhada apresenta uma fonte de dados clara e abrangente e uma galeria de imagens completa, acessível de quase qualquer lugar na aplicação Fozzels.

###
Acessando a Visualização Detalhada

A Visualização Detalhada do Produto é estrategicamente acessível através de múltiplas localizações na plataforma Fozzels para garantir acesso rápido aos dados principais do produto:

1\. Catálogo e Dashboards: Os usuários podem abrir a visualização diretamente do Catálogo de produtos principal ou dos Dashboards de Fluxo.
![](/img/kb/data-import-and-quality/detailed-product-view-reviewing-all-attributes-for-a-single-product/_15ma3e15kOEv7H6Zw8goXP94TLycjWCsQ.png)

2\. Navegação Direta: O acesso geralmente é iniciado clicando em um identificador único do produto (como o SKU ou ID do Produto) ou simplesmente clicando na miniatura de imagem do produto.
![](/img/kb/data-import-and-quality/detailed-product-view-reviewing-all-attributes-for-a-single-product/QPXZYuU1rbS9KlQlcpm_jYQK6E3G_-9z3A.png)

###
Proposta de Valor para o Usuário

A Visualização Detalhada do Produto fornece dois benefícios principais: clareza de dados e completude visual.

1\. Informações de Atributos Unificadas. A visualização substitui a necessidade de navegar pelas colunas largas e complexas da tabela do Catálogo principal. Apresenta uma lista limpa, verticalmente rolável, de todos os atributos ativos e seus valores atuais, garantindo que os usuários possam verificar rapidamente cada ponto de dados disponível para um produto. Esta lista é restrita apenas aos atributos atualmente ativos na integração, minimizando a confusão visual.

2\. Verificação de Ativos Visuais. O lado direito da visualização exibe com destaque todas as imagens associadas ao produto em um bloco de galeria dedicado. Esta seção permite inspeção visual rápida:

Visualização de Imagem: A foto principal no bloco de visualização muda dinamicamente quando o cursor passa sobre qualquer imagem na faixa de galeria, exibindo imediatamente o ativo em tamanho completo.
Indicador de Usabilidade: Uma dica visual clara, como uma borda grossa, aparece ao redor da imagem sobre a qual está passando o mouse, confirmando qual ativo está no momento na área de visualização principal.

3\. Vinculação Externa. Para verificação externa prática, a visualização inclui um hiperlink direto dentro do atributo "Product Absolute URL", permitindo ao usuário abrir a página web ao vivo do produto na loja de e-commerce integrada com um único clique.

Criar um Content Flow para categorias é praticamente idêntico a trabalhar com produtos – a interface é familiar, prática e intuitiva. Veja abaixo um guia passo a passo de como configurar e iniciar a geração de conteúdo para suas categorias.

## Guia passo a passo

### Passo 1. Acesse Categories

No menu lateral, em **MAIN/CATALOG**, selecione **Categories**.
![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/ma3pY8yLxxW9bLdy8jQZY6oWK-uoZiMiiA.png)

### Passo 2. Selecione a Store View

No topo da página, use os filtros do seletor de loja para garantir que você selecionou a store view correta.

### ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/1dojt8GKF7WJ4UfUGbaSXAoXnYw-c2EhlQ.png)

### Passo 3. Selecione as categorias

Escolha as categorias para as quais você quer gerar conteúdo:

-   **Manualmente:** Marque as caixas ao lado das categorias desejadas na lista.

-   **Via Mass Action:** Selecione **Create Content Flow** no menu suspenso `Actions` acima da tabela.

> _Observação:_ A interface de seleção é idêntica à do fluxo de produtos, o que torna o processo rápido e fácil.

### ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/IZYD-wiFeEnNG1Ypw6QzBg6w1iNpWI5Ipg.png)
Passo 4. Crie o Flow e configure os ajustes principais

1.  Informe um **Name** claro para o flow (por exemplo, _Description for Mens collection_).

2.  O campo **Entity Type** já vem pré-selecionado como `Category`.

###
Passo 5. Escolha o atributo de destino

No menu suspenso **Attribute**, selecione o atributo de categoria para o qual você quer gerar conteúdo (por exemplo, `Description`) e salve sua seleção.

> **E se o atributo necessário não estiver na lista?**
>
> 1.  Vá em **Integrations** (menu à esquerda) → aba **Attributes**.
>
> 2.  Selecione **Entity Type** → `Category`.
>     ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/8MMJXlxfi3GgqtgxIQfI_XZ5F1VbdlhHtA.png)
>
> 3.  Encontre o atributo necessário na lista.
>
> 4.  Verifique a propriedade **Mutable**: se estiver desativada, ative-a para permitir atualizações de conteúdo nesse atributo.
>     ![](/img/kb/content-creation-flows/how-to-create-a-content-flow-for-categories-in-fozzels/wF2PLUJw__aF3ktzhc2gqAQN6hQeKV-Cew.png)
>

Passo 6. AI Configuration, Prompt e execução

1.  Escolha o modelo de IA de sua preferência.

2.  Aplique filtros adicionais, se necessário.

3.  Digite seu **Prompt**.

4.   Adicione as configurações de automação.

5.  Ative seu flow.

6.  Salve o flow.

7.  Clique em **Run Now** para iniciar a geração.

## Informações adicionais

Todos os recursos e mecanismos relacionados funcionam **exatamente como nos flows de produtos**:

-   **Daily Total Batch List:** Os resultados da geração de categorias também aparecem no relatório diário geral.

-   **Batch Lists** e regras gerais de geração.

-   Automação e exportação/importação de dados.

-   Formatação, palavras proibidas / expressões suspeitas.

-   Tags HTML permitidas e mecanismos de overlapping.

Boa geração!

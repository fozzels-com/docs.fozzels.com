## How do I set up a new Fozzels account with a PIM connection?

To set up a new account with a PIM connection (e.g. Katana), provide: the user's email address and the PIM API key. The Fozzels team will create the account, set up the connection, and send login credentials to the user.

## How do I connect my Magento store to Fozzels?

Contact the Fozzels team and provide: the store URL, the email address for the user account, and specify whether you need a trial or paid account. The team will set up the connection and create the account with login credentials.

## Can I get a trial account for Fozzels?

Yes, Fozzels offers a 14-day free trial. During the trial you don't pay for the license, but you do pay for AI token usage. Connect your credit card in account settings. The team will set up your integration and create initial prompts.

## How does the Fozzels free trial work?

14-day free trial, no license fee but AI token costs apply. A credit card is required. The team sets up your integration, creates initial prompts, and can schedule a call to walk you through everything.

## How do I connect my Shopware 6 store to Fozzels?

Provide the Fozzels team with your Access Key ID and Secure Access Key from the Shopware admin panel. For a detailed guide, see the Shopware integration article.

## How do I create an API key in Shopware 6 for Fozzels?

In Shopware admin go to Settings → System → Integrations and create a new Integration, which generates an Access Key ID and Secret Access Key. Use the Integration key (starts with `SWIA...`), not the Sales Channel key.

## How do I connect my Shopify store to Fozzels (2026 update)?

Since recent Shopify changes, the store owner must create a custom App via the Shopify DEV Dashboard. Follow the guide, then provide: Store URL, API Key, API Secret, App Host Name, and whether you use Markets or LangShop.

## What information does Fozzels need from me to set up a Shopify integration?

You need: Store URL, API Key, API Secret, App Host Name, and whether you plan to connect Markets or LangShop. The store owner creates a custom App via the Shopify DEV Dashboard.

## Why can't I complete the Shopify integration with collaborator access?

Shopify requires the Store Owner to apply specific settings in the Dev Dashboard. The Fozzels team can schedule a 20-minute Google Meet call to guide the Store Owner through the steps.

## How do I connect my Lightspeed store to Fozzels?

Create an API key in Lightspeed (grant product edit permission), then send the API Key and API Secret to the Fozzels team.

## Can Fozzels integrate with Akeneo PIM?

Yes, Fozzels can build an integration with Akeneo PIM. A custom text field can be created in Akeneo where Fozzels writes content. Contact the team to discuss setup.

## How do I add new websites to my Fozzels account?

Create a new integration in Fozzels with unique API keys for each website. Each site needs its own API credentials — you cannot reuse keys from another site.

## Can I set up multiple user accounts for my team?

Yes, Fozzels supports multiple user accounts per store with different access levels (e.g. manager access across multiple stores). Contact support to set up additional accounts.

## Can multiple users share one Fozzels account?

Do not share login credentials. Each colleague should get their own account: a Reseller can send an invitation, and the invited user sets their own password. See [Team Access Management: Fozzels Roles Guide (Customer vs. Reseller)](/account-core-resources/team-access-management-fozzels-roles-guide-customer-vs-reseller) for the full flow. For some plans, separate accounts with manager access can be created — contact support.

## What are the Fozzels subscription plans?

Plans range from Basic Light (€299/month) to Unlimited (€999/month), all cancelable monthly. Higher plans offer more daily generation limits, prompt flexibility, and image/video generation capabilities.

## How do I choose a subscription plan after setup?

After logging in, go to the "Upgrade your account" section and select your plan. Contact support for guidance.

## How do I sync generated images to my webshop?

Approve the image → hover and select **Synchronize** → wait for the "Synchronized At" timestamp → check the results on your website.

## Loading icons show for hours during image sync.

Sync isn't instant. If the loading state persists for 30+ minutes, contact support. Make sure you completed both the approval and sync steps.

## How do I create a single image flow (top only / bottom only)?

Create a new image flow, select the "Single image" type, and choose one product. Only that item will be used.

## My image flow isn't working / I get a model error.

AI model providers may update their specs. Try switching to an alternative model (e.g. Gemini 3 Pro, GPT Image 1). The team will update when the model is back.

## How do I activate and confirm an image flow?

Make sure your flow is both activated (page 1) and confirmed (page 2). Both steps are required.

## Can Fozzels remove backgrounds from product images?

Yes, Fozzels can do AI-based background removal. For some PIMs, pushing edited images back isn't supported — manual download is available.

## Can I push AI-generated images to my PIM?

Not all PIMs support image push via API. Some integrations (Shopify, Shopware) support it. Manual download is always available.
